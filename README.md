# RepoLens

GitHub のリポジトリを調べるための Chrome 拡張です。

- **調べ物**: 開いているリポジトリの事実(説明・スター・ライセンス・最終コミット・最新リリースなど)を、出典の行つきの Markdown でコピーします。
- **公開点検**: 自分の公開リポジトリを、決めたルール(名前・LICENSE・README・コミットのメールアドレス・ビルド成果物・GitHub Actions の書き方など)で点検して、○ × で並べます。

GitHub の非公式の拡張です。GitHub, Inc. とは関係ありません。

## 主な機能

- **popup**: リポジトリのページでアイコンを押すと、事実の一覧と「箇条でコピー」「表の行でコピー」が出ます。自分のリポジトリなら、その場で 14 項目を点検します。
- **ショートカット**: `Alt+Shift+G` で popup を開かずにコピーします(結果はアイコンのバッジに出ます)。
- **公開点検のページ**: 自分の公開リポジトリをまとめて点検し、表にします。結果は Markdown の表でもコピーできます。
- **GitHub Actions の点検**: `.github/workflows/` のファイルを読んで、2 項目を見ます。
  - C-13 危ない書き方: `pull_request_target`・`workflow_run` のきっかけ、`run:` の中の `${{ github.event.* }}`、self-hosted のランナー、permissions が無い
  - C-14 守りの書き方: `uses:` を SHA で固定、checkout の `persist-credentials: false`、`timeout-minutes`、`concurrency`、一番上の permissions に書き込みの権限を置かない
  - YAML は全部は読みません(依存なし)。字下げと行の形で見るので、アンカーや複数行の引用文字列の中は見落とします。
- **設定のページ**: 点検するユーザー名、コピーの形、点検のルール(許可するメールアドレス・ビルド成果物の拡張子など)を変えられます。

## 動作環境

- Chrome 153 以降(パソコン版)
- GitHub の REST API を **認証なし** で呼びます。上限は 1 時間に 60 回(IP ごと)です。残りの回数は設定のページに出ます。
- 権限は `activeTab`・`offscreen`(クリップボード)・`storage` だけです。`host_permissions` はありません。
- 外に送るのは `api.github.com` への読み取りの通信だけです。取った事実は 10 分だけ `storage.session` に置きます。

## 入れ方

1. このリポジトリをダウンロードして展開します。
2. `chrome://extensions` を開き、「デベロッパー モード」を ON にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選びます。
4. **設定のページで「GitHub のユーザー名」を自分のものに変えます**(初期値は作者のユーザー名です)。

ビルドはありません。ファイルをそのまま読み込みます。

## テスト

Node.js 22 以降で、このフォルダから:

```
node --test tests/
```

依存パッケージはありません。API の応答の見本(`tests/fixtures/api/`)は GitHub の公開文書から作ったもので、実物の応答ではありません。
