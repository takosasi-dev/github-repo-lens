設定

保存した設定が読めないので、既定値で動いている。保存を押すまで元の値は上書きしない

公開点検

ownerLogin

空にすると公開点検を使わない

点検に含めるincludeForks・includeArchived

コピーの形

ショートカットでコピーする形defaultFormat

ショートカット copy-repo が popup を開かずに入れる形

箇条の形bullet
表の行の形includeHeader

popup の印の既定。ショートカットにも使う

点検のルール

extraAllowedEmails

ユーザー名から作る noreply のアドレスは書かなくても許可する

binaryExts

カンマで区切る

junkNames

カンマで区切る。パスの最後の部分と比べる

README の見出しのキーワードreadmeHeadingKeywords

見出しにどれか1つが入っていれば、その項目があるとみなす。カンマで区切る
